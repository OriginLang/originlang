# Plugin Scaffold

此目录将承载插件脚手架的通用逻辑，供 `ol plugin init` 调用。

预期职责：

- 根据语言、运行时载体和贡献点选择兼容模板；
- 校验插件 ID、目标目录、OriginLang 版本与模板参数；
- 先计算完整文件计划，再以原子方式写入生成结果；
- 默认拒绝覆盖非空目录，只有显式参数才允许可审计的覆盖策略；
- 在生成后校验 manifest、入口和最小测试文件是否匹配。

此处不保存模板原文件，也不调用语言构建器；模板位于 `../templates/plugin/`，命令编排位于 `../commands/plugin/`。

当前仅预留目录，尚未实现生成逻辑。
